## 用户故事生成 UI 交互重构
- **问题**：旧版 split button + dropdown 设计混乱，用户找不到 Kimi 选项；LLM 生成期间无加载反馈，30s+ 等待期间无法判断请求是否发出
- **改造**：
  - 策略选择器：卡片式三选一（⚡合并生成/Kimi 智能拆分/📐按工作量拆分），每张卡片含图标+描述+状态标签，选中高亮蓝边框+✓标记
  - Kimi 卡片实时显示连接状态（已连接/未配置）
  - 生成按钮统一在策略选择器下方，按钮文案根据策略动态变化（"生成用户故事"/"Kimi 智能生成用户故事"）
  - 生成中：按钮变 loading + 实时耗时秒数（"Kimi 正在分析需求… 23s"）；故事面板显示加载遮罩+提示文字
  - 生成完成后：黄色提示条+确认落库按钮带数字角标
  - 已保存状态：绿色标签显示"✓ 已保存 N 条"
- **技术细节**：selectedStrategy ref 默认 rules_v2；storyGenLoading/storyGenElapsed 实时状态；setInterval 计时器在 finally 和 onBeforeUnmount 清理
- **验证**：vite build ✅ / vitest 7/7 ✅ / 端到端 HTTP Kimi 生成 30.9s, 2 stories ✅
