  3. `git fetch origin` 从 GitHub 取回完整对象库 → `origin/main=3ea191b`（有效）。
  4. `git checkout -B main origin/main -f` 重置本地 main；从备份拷回 TASKS.md/memory/specs。

- 教训：该仓库 git 元数据脆弱，后续提交/推送前先 `git fsck --quick` 自检；避免在损坏态强推。
