# kc4-6 知识中心 UI 三视图重构 + 产品圣经去硬编码

- 分支：认领后建子分支 `feature/kc4-6-ui-views`，PR 合入 `feature/kc4-knowledge-hub`（Vicky2号 审查合版）
- 级别：S2
- 参考：`docs/kc3_knowledge_hub_plan.md` §4.5 / §5(kc4-6)

## 目标
知识中心 UI 从 5 个割裂 Tab 收敛为 3 个以业务为中心的视图；产品圣经去硬编码 `PRODUCT_BIBLE`，并入主笔记产商品章节。

## 三视图
1. **业务全景 HUB**：领域树 + 主笔记预览 + 业务时间线（kc4-3）+ 一键同步（kc4-2）。
2. **知识检索**：统一检索（知识库笔记 + SQL脚本[kc4-5] + 关联），按 domain / 类型 / tag 过滤，废弃 Obsidian 文件夹树导航。
3. **沉淀向导**：替换错配的「知识沉淀」Tab（速记收件箱 + 一键沉淀 + 关联 domain）；SQL脚本库保留入口（kc4-5 已补 domain）。

## 边界
- 产品圣经：删除 `PRODUCT_BIBLE` 硬编码配置，改为读主笔记 §2 产商品章节（或 `domain_code` 聚合），前端 `ProductBibleView` 接入 HUB。
- 现有 `KnowledgeView` / `ProductBibleView` / `DomainKnowledgeView` / `OperationNotesView` 收敛或弃用，避免白屏。

## 落点文件
- `frontend/src/views/KnowledgeCenterView.vue`：重构为 3 Tab。
- `frontend/src/views/ProductBibleView.vue`：去硬编码，读主笔记产商品。
- `backend/core/config.py`：移除 `PRODUCT_BIBLE`（或保留兼容读取主笔记）。
- 图标 import 必须存在（防无头冒烟白屏）。

## 验收
- 3 视图路由可达、无白屏；`npm run build` 干净。
- 无头浏览器冒烟：时间线组件渲染、同步按钮生效。

## 依赖
- blockedBy **kc4-3**, **kc4-4**, **kc4-5**（UI 依赖对应接口）。
