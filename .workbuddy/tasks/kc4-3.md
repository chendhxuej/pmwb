# kc4-3 业务时间线接口 business_timeline + 前端组件

- 分支：认领后建子分支 `feature/kc4-3-timeline`，PR 合入 `feature/kc4-knowledge-hub`（Vicky2号 审查合版）
- 级别：S2
- 参考：`docs/kc3_knowledge_hub_plan.md` §4.3 / §5(kc4-3)

## 目标
落地老大核心诉求：「从关联关系看这个业务历史各时间点干了什么事」——按业务维度聚合所有知识关联事件，时间倒序呈现。这是缺口 B（业务时间线缺失）的修复。

## 落点文件
- `backend/routers/knowledge.py`：`GET /api/v1/knowledge/business-timeline?domain_code=&limit=`
  读 `pmwb_knowledge_link`，按 `event_date desc, created_at desc` 排序，返回 `{event_type, event_date, summary, source, link_url}`。
- 前端：`KnowledgeCenterView` 内嵌时间线组件（时间轴样式，点开跳源记录 / 笔记）。

## 验收
- 选一业务，时间线显示该业务全部关联事件，按时间排序。
- 空业务返回空列表不报错。

## 依赖
- blockedBy **kc4-1**（读 link `event_date/event_type`）。
