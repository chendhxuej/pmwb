# pb-5（L5）风险事件（按工单维度）

- 级别：S1 ｜ blockedBy：pb-2, pb-3 ｜ 状态：⬜待分配
- 方案章节：4.7 / 5.7 / 7.7 / 9-B5 / 10-AC-E

## 目标
风险有人记、有人管，且影响上线的未消除风险能真正挡住「已上线」。

## 范围
- `pmwb_pb_risk` 全新实体：工单锚、风险类型（闭集）、描述、影响上线标记、发现来源、登记人/时间、处置、消除状态与时间、原文引用。
- 自动三类事件：环节回退、环节截止超期、上线失败与顺延；由 pb-3 事件触发，不在页面另写一份判定。
- 反馈自动登记与**合并更新**：按 (工单, 风险类型, 未消除) 合并，不新建重复风险；来自 pb-7 的反馈原文保留。
- 硬门禁：任一「影响上线且未消除」风险存在 → 拒绝登记「已上线」，返回可读原因与风险清单。

## 边界
- 风险按工单维度，不做项目级风险台账；不做审批流。
- 不自动发邮件、不自动判定风险等级（人只在过程外定口径）。

## 验收
- 同一工单同一类型未消除风险重复登记/反馈 → 合并为一条，留痕追加不覆盖原文。
- 有未消除影响上线风险时上线登记被拒；风险消除后可登记。
- 上线失败自动顺延同时自动生成风险记录，且不重复。
