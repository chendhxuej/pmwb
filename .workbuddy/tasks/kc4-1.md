# kc4-1 关联表扩展 link：event_type / event_date / summary

- 分支：`feature/kc4-1-link-events`（Vicky2号 已认领，🔵开发中；合入父分支 `feature/kc4-knowledge-hub`）
- 级别：S2
- 参考：`docs/kc3_knowledge_hub_plan.md` §3.1 / §5(kc4-1)

## 目标
扩展 `pmwb_knowledge_link`，让每条关联携带「业务事件」语义，支撑业务时间线（kc4-3）与主笔记 §8 变更轨迹自动生成。这是整条闭环的数据基础。

## 边界
- 仅加列，不删不改既有列；既有数据不丢。
- `event_type`：事件类型枚举（requirement_close / meeting / operation_ticket / delivery / rule / manual 等），由沉淀引擎写 link 时填充。
- `event_date`：业务发生日期（naive date，业务日期，非 created_at）；存量用 created_at 日期回填。
- `summary`：一句话事件摘要（如「需求#123 上线：一网通宽带新增 FTTR 融合包」）。

## 落点文件
- `backend/db/models.py`：`PmwbKnowledgeLink` 加 3 列。
- alembic 迁移：先 `alembic heads` 取最大号 +1（勿用 `20260804000001` 等已占用号）。
- 存量回填脚本：`UPDATE pmwb_knowledge_link SET event_date=DATE(created_at) WHERE event_date IS NULL;`；`event_type` 按 link_source 推断默认值。

## 验收
- `alembic upgrade head` 通过；表结构含 3 新列。
- 存量 link 全部 `event_date` 非空。
- 既有 `sediment_*` 写 link 处补充 `event_type/event_date/summary`（最小集本任务补，全量随 kc4-2 一并收敛）。
