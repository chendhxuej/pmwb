# pb-8（L7）版本概览与口径

- 级别：S2 ｜ blockedBy：pb-1~pb-7 ｜ 状态：⬜待分配
- 方案章节：2.2 / 6.1 / 5.6 / 10-AC-G

## 目标
一屏看清本版应上几单、卡在哪个环节、哪些没上成、哪些是人工例外，且所有数字与下钻同源。

## 范围
- 指标卡：本版应上 / 各环节分布 / 超期 / 有影响上线未消除风险 / 已上线 / 未达成 / 顺延来的 / 人工例外 / 回执率 / 待核对量。
- 清单：**顺延清单、连续顺延异常清单（≥3）、人工例外清单**、风险清单、待补版本计划清单。
- 唯一取数服务，指标与下钻共用同一 `_track_where(version)`；**人工例外单列且不进按计划上线率分子**。
- 进行中版本不补 0；`data_until` / 口径标注随数据返回。

## 边界
- 禁写死快照值（项目历史事故）；禁前端自行推导簇数/分母（后端一次返回）；展示字段 = 排序字段 = 下钻字段 = 同一版本。

## 验收
- 任一指标卡下钻列表条数 = 卡片数，筛选条件一致。
- 人工例外放行后概览出现独立标记，按计划上线率分子不变、分母 +1。
- 顺延后原版计未达成、新版计在跟，全局在跟数按主行去重。
