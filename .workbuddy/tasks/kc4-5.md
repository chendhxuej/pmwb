# kc4-5 SQL脚本库补 domain_code

- 分支：认领后建子分支 `feature/kc4-5-sql-domain`（**开放认领**，可与 kc4-1 并行），PR 合入 `feature/kc4-knowledge-hub`（Vicky2号 审查合版）
- 级别：S2
- 参考：`docs/kc3_knowledge_hub_plan.md` §3.3 / §5(kc4-5)

## 目标
SQL脚本库（`pmwb_sql_script`）补齐 `domain_code`，纳入业务知识领域体系，检索可按 domain 过滤（老大决策：补齐关联后保留，不移出）。

## 边界
- 表增 `domain_code` 列（可空，向后兼容）；迁移。
- CRUD 改造：新增 / 编辑支持选 domain；列表 / 检索支持 domain 过滤。
- 知识中心「知识检索」视图纳入 SQL 脚本（按 domain 联动）。

## 落点文件
- `backend/db/models.py`：`PmwbSqlScript` 增 `domain_code`。
- `backend/routers/sql_script.py`（或现有）：CRUD + 过滤参数。
- alembic 迁移。

## 验收
- SQL 脚本可标 `domain_code`；检索按 domain 过滤生效。
- 无 domain 的旧数据不报错。

## 依赖
无（可与 kc4-1 并行）。
