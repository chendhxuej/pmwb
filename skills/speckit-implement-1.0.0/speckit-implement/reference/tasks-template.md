# 任务：[FEATURE NAME]

**输入**: 设计文档来自 `/specs/[###-feature-name]/`
**前置文档**: plan.md、spec.md、research.md、data-model.md、contracts/

**测试要求**: 若宪章要求测试优先，请先写测试（Red），再写实现（Green）。

**组织方式**: 任务按用户故事组织，以支持独立执行与独立验证。

## 格式：`[ID] [P?] [Story] 任务描述`

- **[P]**：可并行执行
- **[Story]**：所属用户故事
- 描述中需包含文件路径
