1. 背景与目标

营销旺季实名制短信通道峰值积压，成功率由 99.2% → 96.5%（数据源：BOSS 运营月报 2026-10，见引用 [S2]）。目标：峰值成功率恢复 ≥99%，不中断在途短信。

2. 范围与边界

  • 纳入：CRM 优先级队列、BOSS 批价规则、订单中心变更流水。
  • 排除：国际短信通道、非实名制下行（明确排除项）。

3. 业务角色与权限

Channel 运营（队列配置）、财务（批价复核）；数据范围限于本省签名，跨省不开放。

4. 业务流程与状态

主流程：队列优先级判定 → 通道选择 → 发送 → 批价 → 流水落账。异常：通道满时降级至备用队列并回执。

5. 业务规则与验收标准

  • 原子规则 R1：峰值≥500 条/秒时启用优先级队列（现行，权威 A）。
  • 验收 A1：运营人员在旺季峰值场景可观察到成功率 ≥99%，失败回执 ≤2s。

6. 待确认 / 变更记录 / 参考资料

6.1 待确认：跨省签名是否纳入（见冲突 CL-高）。6.2 变更记录：v1.0 初稿。6.3 参考资料：见右侧引用来源 6 条。
